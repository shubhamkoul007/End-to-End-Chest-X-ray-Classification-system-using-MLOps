Project pipeline 

1. First we made repo in GitHub. 
2. Then cloned it in our machine. 
3. Then ran a template.py to have folders and files structure like we want. 
4. Then we made a requirements.py and setup.py, ran requirements.py which also 
ran setup.py and got requirements package in our src. 
5. Then we added logger in init inside src/cnnClassifier. 
6. We made a main (at repo level) to test the above logger.
7. Then we made common.py inside utils folder to have common functions.
